## AWS CLI

The [AWS Command Line Interface (AWS CLI)](https://aws.amazon.com/cli/) is a unified tool to manage your AWS services. With just one tool to download and configure, you can control multiple AWS services from the command line and automate them through scripts.

The fastest way to get started with the AWS CLI is to use [AWS CloudShell](https://aws.amazon.com/cloudshell/) , a browser-based shell. This service runs in the AWS console and inherits your user identity, so there's no need to set long-lived security credentials. CloudShell runs on Amazon Linux 2023 and you can install additional packages if needed. You are limited to 1GB of storage. You could also use AWS Toolkit for VSCode, please refer to this guide for instructions [Installing the AWS Toolkit for Visual Studio Code](https://docs.aws.amazon.com/toolkit-for-vscode/latest/userguide/setup-toolkit.html)

To access AWS CloudShell from the console, use the [console link](https://console.aws.amazon.com/cloudshell) .

The [AWS CLI Command Reference](https://awscli.amazonaws.com/v2/documentation/api/latest/reference/index.html) provides CLI commands for all services, for example:

- [Amazon Bedrock](https://awscli.amazonaws.com/v2/documentation/api/latest/reference/bedrock/index.html)
	- [Amazon Bedrock Runtime](https://awscli.amazonaws.com/v2/documentation/api/latest/reference/bedrock-runtime/index.html)
- [Amazon SageMaker](https://awscli.amazonaws.com/v2/documentation/api/latest/reference/sagemaker/index.html)
- [Amazon S3](https://awscli.amazonaws.com/v2/documentation/api/latest/reference/s3/index.html)
	- [Amazon S3 API](https://awscli.amazonaws.com/v2/documentation/api/latest/reference/s3api/index.html)
- [AWS IAM](https://awscli.amazonaws.com/v2/documentation/api/latest/reference/iam/index.html)

## AWS SDK

The [AWS Software Development Kit (AWS SDK)](https://aws.amazon.com/developer/tools/) is a set of platform-specific building tools for developers. AWS SDK is available in 12+ languages, so you can choose the right one based on your team's preferences.

Depending on your use case, you may need to use the [Amazon SageMaker Python SDK](https://sagemaker.readthedocs.io/en/stable/) , an open source library for training and deploying machine-learned models on Amazon SageMaker.
